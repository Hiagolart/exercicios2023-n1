# exercicios2023-n1
Repositórios para armazenar exercícios de JS desenvolvidos no últimos mês

## desenvolvimento-produto

Sistema de desenvolvimento de produto: painel do portfólio (abas por classe, produtos agrupados por linha) e tela com as etapas de desenvolvimento de cada máquina. Abra `desenvolvimento-produto/index.html` no navegador. Os produtos e as etapas ficam em `desenvolvimento-produto/data.js`.
